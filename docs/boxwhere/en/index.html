BoxWhere: know which box to open

Start with a box number

Number your boxes and record items and photos. Search an item to find the box to open. Handwritten numbers work; no printer is required.

First-release features

Boxes and items; rooms, packing status, fragile and priority flags; Chinese and English; moving checklist; complete backup and restore; PDF lists and QR labels.

Offline, one-time purchase

All features are planned as a one-time paid app, with no accounts, ads, subscriptions or developer data collection. Release preparation is in progress. No App Store download link is available yet.
