CrateNote: know what is in every box

Number boxes and record items, quantities, notes, and optional photos. Search by item, note, or box number to know what to open.

Available version

Version 1.0 is currently on the App Store. It includes box and item lists, notes and optional photos, a moving checklist, PDF lists and labels, and local backup and restore. No account, ads, or subscriptions. See the App Store for the current price.

Version 2.0 in preparation

The 2.0 draft adds a place hierarchy, on-device photo and speech entry, an item graph, recently deleted recovery, and unboxing clips. These features will be available only if Apple approves and releases the update. Check the App Store for the version currently available.
