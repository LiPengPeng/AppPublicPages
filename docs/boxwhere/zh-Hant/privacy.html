隱私權政策

本政策說明箱裡 / CrateNote 如何處理 App 資料及本網站的瀏覽資訊。

更新日期與適用範圍

更新日期：2026-10-15。本政策適用於 CrateNote iOS App 及本網站。功能依版本而異；以下說明目前的 1.0 與準備中的 2.0。

裝置上的記錄

物品、位置、備註、清單和照片儲存在裝置上的 App 資料中。開發者沒有用來收集這些內容的伺服器，也不使用廣告、分析或追蹤 SDK。iOS 裝置備份是否包含 App 資料，取決於系統設定。

照片與相機

系統照片選擇器只提供你主動選取的圖片；App 不會要求完整相簿存取權。只有在你選擇拍照時才會要求相機權限。1.0 中主動附加的照片會儲存在本機。2.0 照片辨識在裝置端完成，原始照片預設不保留；你可選擇為每件物品保留約 60 KB 的壓縮縮圖。照片不會傳送到開發者伺服器。

語音與影片

如果你使用的版本含有這些功能，語音辨識會強制在裝置端執行，不會上傳或儲存錄音；裝置不支援離線辨識時，App 會請你改用打字或照片。開箱影片最長 30 秒，儲存在本機，不包含於 App 匯出的備份。

匯出、分享與刪除

你主動匯出的備份和 PDF 會包含所選記錄；接收者或你選擇的雲端檔案服務可能取得這些內容。QR Code 只包含本機記錄 ID，無法遠端查詢。2.0 刪除的記錄會保留 30 天供還原。解除安裝會刪除本機 App 資料與安全副本；系統備份和匯出檔案請自行管理。

外部服務與聯絡

Apple 處理 App Store 購買及退款申請。本網站由 GitHub Pages 託管；GitHub 隱私聲明指出，服務可能處理 IP 位址、裝置資訊和網站瀏覽記錄等服務使用資訊。寄送支援郵件會提供郵件中的資訊，請勿寄送密碼或不必要的私人資料。
