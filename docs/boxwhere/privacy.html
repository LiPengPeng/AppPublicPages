本机记录

箱子、物品、照片、备注和清单保存在 App 本机沙盒。开发者不接收这些数据。没有账号、广告、追踪或分析 SDK。系统设备备份可能包含数据，由你的系统设置决定。

照片与相机

系统照片选择器仅提供你主动选择的照片，不请求完整相册访问。仅主动拍照时请求相机权限。照片压缩后保存在本机，不上传到开发者服务器。

导出与分享

你主动导出或分享的备份、PDF 包含所选记录，接收方和存储服务可能获得内容，请谨慎选择接收方。二维码只包含本机箱子记录 ID，不包含物品内容，不提供远程查询。

外部服务

公开页面由 GitHub Pages 托管；打开页面时，托管方可能处理 IP 地址等常规网络请求信息。App Store 购买由 Apple 处理。发送支持邮件会向支持方提供你主动发送的内容，请勿发送密码或不必要的私人资料。

删除和恢复

可删除箱子/物品或在设置清除当前记录。恢复备份前保留旧文件安全快照；清除当前记录不会删除快照或外部导出文件。卸载删除本机沙盒与快照；系统备份和外部文件需自行管理。

联系
