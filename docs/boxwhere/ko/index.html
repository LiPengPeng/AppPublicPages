CrateNote: 상자마다 무엇이 들었는지 기록하세요

상자에 번호를 붙이고 물품, 수량, 메모, 선택 사진을 기록하세요. 이름, 메모, 상자 번호로 검색하면 열 상자를 바로 찾을 수 있습니다.

수납과 이사

물건과 보관 위치를 기록하고 필요할 때 검색하세요. 상자 목록, 사진·음성 입력, 위치 계층, 기기 내 백업과 복원을 지원합니다.

개인정보와 가격

기록은 기본적으로 기기에 저장됩니다. 계정, 광고, 구독은 없습니다. 일회성 앱 내 구매가 제공될 수 있으며 실제 기능과 가격은 App Store에서 확인하세요.
