平衡球：惯性迷宫

隐私政策

更新日期：2026 年 10 月 3 日

本政策适用于 iPhone 游戏「平衡球：惯性迷宫」。本政策中的“我们”指 App Store 产品页面所列的开发者。游戏无需注册账号，以本机游玩为主。

1. 游戏数据

游戏在本机保存已解锁关卡、最高得分和声音开关，用于继续挑战和保留设置。我们没有设置主动上传这些存档的功能，不提供云同步、广告、购买或使用分析服务，也不使用广告标识符进行追踪。

2. 引擎及系统功能

游戏引擎和系统会使用运行游戏、计时以及读写本机文件所需的接口。工程中的分析、广告、崩溃上报、内购和云服务配置为关闭。我们不会通过这些接口建立用户画像。设备系统本身的诊断、备份及恢复由 Apple 和用户的系统设置管理。

3. 保留及删除

本机进度保留在应用的数据目录内。卸载应用通常会移除这些本地数据；系统备份和之后的恢复可能保留或恢复数据，按系统设置管理。本游戏没有账号或开发者服务器上的游戏存档，因此无需申请删除服务器账号。

4. 支持邮件

你主动联系支持时，我们会收到你提供的邮箱、问题描述和附件，仅用于答复及处理该问题。请勿提供密码或不相关的个人资料。支持邮件通过邮箱服务商处理，适用其服务政策；需要删除相关支持记录时，可通过下方邮箱提出请求，我们将在完成必要的问题处理后删除不再需要保留的内容。

5. 外部页面

你主动打开隐私或支持页面时，系统浏览器会访问托管在 GitHub Pages 的网站。网站提供商可能为页面交付及安全记录 IP 地址和访问日志，其处理方式以 GitHub 隐私声明为准。我们的页面不安装广告或访问统计脚本。游戏不要求打开网页才能游玩。

6. 政策更新与联系

如游戏功能或数据处理方式发生变化，我们会更新本政策及日期，并按需要提供提示。隐私问题或支持记录删除请求，请联系 wf8.8@qq.com。
