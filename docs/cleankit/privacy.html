清爽空间隐私政策

生效日期：2026-10-14 隐私与支持联系：wf9.9@qq.com

适用范围

本政策适用于清爽空间 iOS 应用。应用提供授权照片和视频整理、用户选择文件夹扫描、媒体压缩、本应用缓存管理及本地扫描提醒。

应用处理的信息

  • 照片：只有在你主动开始扫描或优化并授予照片访问权限后，应用才读取授权范围内的照片信息和本机缩略图，并在设备上生成相似、低质量、截图和旧照片候选。扫描和优化不会自动下载尚未保存在设备上的 iCloud 原件。
  • 照片与视频预览：轻点照片或视频缩略图主动打开预览时，如果原件只保存在 iCloud，系统 Photos 可能按你的 iCloud 和网络设置取回该媒体；应用会显示加载状态。媒体由 iOS PhotoKit 处理，不会发送给应用服务器或广告服务。
  • 视频：为筛选大型视频，应用会在本机读取你已授权且设备可访问的视频资源并累计其字节数；视频压缩也只处理设备可访问的原件。相关扫描和优化 PhotoKit 请求关闭网络访问，不会自动下载尚未保存在设备上的 iCloud 原件；无法在本机读取的项目会跳过。
  • 文件夹：只有在你通过 iOS 文件选择器授予目录访问权后，应用才读取其中可访问项目的名称、类型、大小和修改时间等元数据。文件扫描不会读取文件内容。
  • 设备空间：应用读取可用和总空间，以便在界面中显示设备存储状态。
  • 偏好和手动标记：扫描偏好、提醒设置及手动标记的照片标识保存在本机应用数据中。扫描候选在应用运行期间保存在内存中，重新启动后需要重新扫描。
  • 临时媒体文件：执行照片或视频优化时，应用在设备上创建临时副本；处理结束时清理这些临时文件。保存操作会将副本写入系统照片图库。
  • 本地通知：只有在你开启提醒并授权通知后，应用才安排设备本地的定期提醒。

使用、传输与共享

应用免费下载，不提供账户、订阅或应用内购买。1.0 不加载或展示广告，不启动 Google Mobile Ads、UMP 广告隐私流程或 Apple ATT 请求；AdMob/UMP 代码、SDK 和配置保留在应用中，但由版本开关停用。

由于本版本不请求广告，应用不会发起广告请求，也不运行 UMP 或 ATT 流程。若未来发布版本启用广告，Google Mobile Ads SDK 为加载和衡量广告可能处理 IP 地址（用于估算设备的大致地区）、粗略位置、设备标识符、广告数据、产品交互、崩溃诊断及性能数据；UMP SDK 管理广告隐私选择，其隐私清单还列有粗略位置、产品交互和性能数据。具体处理还受地区消息、用户选择及 Google 隐私政策约束。只有在发布前完成 IDFA 说明、隐私披露和对应配置后，应用才会考虑请求 iOS ATT 授权；用户拒绝后仍可请求不使用 IDFA 的广告。

广告 SDK 不读取应用的照片、视频、文件内容或扫描候选。照片、视频、扫描结果、文件信息、设备空间和偏好由应用在本机处理，不会发送给广告服务。应用没有自有服务器，也没有账号数据。

你保存压缩副本后，系统照片图库可能按你的 iCloud 照片设置同步该项目。设备备份和文件提供商的同步行为由 iOS 及你所用服务的设置决定，不由本应用控制。

可选使用统计

Firebase Analytics 默认关闭。首次启动时，应用会询问你是否同意通过 Firebase Analytics 向 Google 发送基础设备信息和应用使用统计，以了解功能使用情况。不同意不影响照片、视频和文件整理功能。应用不会向统计服务发送照片、视频、文件内容或你输入的文本，也不会添加自定义用户属性或内容级统计事件。Firebase Analytics 集成已关闭 IDFV 收集。1.0 不运行 UMP 广告隐私流程或 iOS ATT 请求；如未来启用广告，这些选择将分别说明。你可随时在“我的 > 隐私与数据”或“我的 > 分析偏好”关闭统计；关闭后停止后续统计收集。CleanKit 的 Google Analytics 报表区域采用美国默认设置；默认共享选项允许 Google 将 Analytics 数据用于基准化分析、技术支持和账号优化，但未启用用于改进 Google 产品与服务的数据共享。报表区域是报表设置，不表示数据仅存储在该地区；有关 Google 的数据处理方式，请参阅 Google 隐私权政策。

保存期限与删除

扫描候选仅在当前运行期间保存在应用状态中。偏好、提醒设置和手动标记保留在本机，直到你更改设置、取消标记或删除应用。iOS 设备备份可能按你的系统设置保留应用数据。

删除照片或视频会通过系统照片图库提交；项目可能由系统保留在“最近删除”中。文件删除只针对你在应用中选择并确认的项目，并受文件提供商权限约束。卸载应用会移除其本机应用数据；照片图库中的媒体仍按系统照片应用管理。

你的选择

照片访问、文件夹选择和通知均由你主动发起。你可以在 iOS 设置中调整照片和通知权限，也可以不使用相应功能。撤销权限后，依赖该权限的功能将无法使用。

儿童隐私

应用不要求创建账户。1.0 的广告集成处于停用状态；如果后续版本启用广告，广告 SDK 可能按上文所述处理设备和广告互动信息。年龄分级依据应用内容和最终广告配置确定。

政策更新与联系我们

如果应用功能、广告 SDK 版本或数据处理方式发生变化，CleanKit 会更新本政策及 App Store Connect 中的隐私披露。有关本政策或个人信息处理的问题，请联系：wf9.9@qq.com。
