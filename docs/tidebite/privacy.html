隐私政策

这款游戏没有账号或开发者云存档；自愿奖励广告由 Google Mobile Ads SDK 提供。

更新日期：2026 年 10 月 9 日。本文适用于 iPhone 游戏“大鱼吃小鱼：深海冒险”。

游戏数据

游戏不要求注册账号，不提供开发者服务器存档或跨设备同步。开发者不会通过游戏接收玩家的关卡进度或分数。Apple 设备备份等系统功能由 Apple 和你的系统设置管理。

广告与第三方服务

游戏仅在失败后提供自愿观看的奖励视频选项，每局最多一次。广告由 Google Mobile Ads SDK 提供。Google 可能处理 IP 地址或大致位置、设备或广告标识符、广告展示与互动信息，以及诊断和性能数据，用于提供和衡量广告、保障服务及防范滥用。具体处理取决于设备、地区、同意状态和 Google 的服务设置。

Google 对数据的处理适用其隐私政策。SDK 数据类别说明见 Google Mobile Ads SDK 数据披露。

同意与隐私选项

游戏集成 Google User Messaging Platform（UMP）以更新广告隐私选择。游戏启动时会更新同意状态；当适用地区的已发布 Google 配置要求显示表单时，UMP 会展示表单；当 UMP 要求提供隐私选项时，游戏菜单会显示入口。实际显示内容取决于所在地区和 Google 后台配置。

联系支持

如果你主动发送支持邮件，我们会收到邮件地址、问题描述及你选择附上的内容，用于回复和处理问题。请勿发送密码或不必要的敏感信息。隐私问题可联系 wf8.8@qq.com。

本网站

本政策页面托管于 GitHub Pages。访问网页时，托管服务可能处理 IP 地址和常规请求日志，以交付网页和保障服务；详情请见 GitHub 隐私声明。本网站不加载广告、统计或追踪脚本。

政策变更

如果游戏功能或数据处理方式发生变化，我们会更新本页和更新日期。请以 App Store 当前版本及本页最新内容为准。
