Politique de confidentialité

Cette politique explique comment ShiftFlow traite les données de l’app et les informations de visite de ce site.

Mise à jour et portée

Mise à jour : 17 octobre 2026. Cette politique concerne l’app iOS ShiftFlow et ce site web.

Données sur votre appareil

Les postes, les cycles, les changements de date, les remarques, les préférences et les copies de sécurité créées avant une restauration restent dans l’espace local de l’app. Le développeur ne reçoit ni ne transfère ces données de planning. Vos commentaires ne sont envoyés que lorsque vous choisissez de les transmettre ; consultez la rubrique Confidentialité des commentaires ci-dessous pour en savoir plus. La sauvegarde iOS peut inclure ces fichiers selon vos réglages système. L’app n’utilise aucun SDK publicitaire ni de suivi.

Notifications

L’autorisation de notification n’est demandée que lorsque vous activez les rappels de poste. Les rappels sont planifiés sur l’appareil et reprennent les noms et horaires que vous avez saisis ; ils ne sont pas envoyés aux serveurs du développeur.

Partage, sauvegardes et e-mail

Les fichiers ne sont exportés ou partagés que sur votre demande. Les sauvegardes contiennent le planning et les remarques ; les images du mois n’incluent pas les remarques. Les destinataires et les services choisis traitent les fichiers selon leurs propres règles. En écrivant à l’assistance, vous transmettez le contenu de votre message ; évitez les mots de passe et les données privées inutiles.

Suppression

Vider le planning conserve vos modèles de poste mais supprime le cycle, les changements de date et les rappels. Les sauvegardes exportées et les copies de sécurité ne sont pas supprimées. La désinstallation supprime l’espace local de l’app ; gérez séparément les sauvegardes système et les fichiers externes.

Services externes

Les pages publiques sont destinées à être hébergées par GitHub Pages, dont le fournisseur peut traiter les informations habituelles des requêtes, comme les adresses IP. Apple traite les achats App Store. Pour toute question de confidentialité, consultez la page d’assistance.

Confidentialité des commentaires

Vous choisissez d’envoyer vos commentaires, reçus et stockés via Cloudflare pour améliorer l’app et résoudre les problèmes. Votre texte, les indications d’utilisation et coordonnées facultatives, ainsi que les versions de l’app et d’iOS et la langue choisies sont transmis au développeur. Aucun planning, aucune note ni aucun identifiant d’appareil n’est joint. Le prestataire traite des données réseau telles que l’adresse IP pour la transmission et la prévention des abus ; les IP ne sont pas enregistrées dans les commentaires. Les commentaires sont supprimés périodiquement après 180 jours ; les sauvegardes du prestataire suivent ses règles de conservation. Pour demander leur suppression, contactez l’assistance avec le numéro de reçu.
