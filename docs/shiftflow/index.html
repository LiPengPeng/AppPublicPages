班序：把工作排好，把生活留出来

循环班次、临时换班、班前提醒和完整备份，全部离线保存在本机。

轮班安排

按顺序加入班次组成循环，例如白、白、夜、夜、休、休，选定第一天日期后保存。支持最长 60 天循环、最多 20 种班次，跨午夜的时间也能正确显示。

提醒与统计

为不同班次分别设置提醒：班次开始时，或提前 15、30、60、120 分钟。统计页可按月、本年或自选区间查看班次次数、合计工时，以及上班、休息与未排天数；不计算工资。

小组件与分享

在主屏幕或锁定屏幕用小组件查看今天的班次，也可以把当月班表导出为图片分享给同事。

本机数据与语言

无需账号，班表和备注保存在本机，可导出完整 JSON 备份。界面支持 10 种语言，以及深浅色、大字号和减少动画。
