技术支持

设置循环

在轮班页按顺序加入班次，选定第一天日期与班表时区，然后保存。月历会向前和向后重复循环。

临时换班

在月历选日期并点换班，可调整当天班次与备注。恢复循环会移除当天调整和备注。

提醒没有响

检查 App 中的系统授权状态和已排截止日期，再检查 iOS 通知设置及专注模式。系统最多保留未来 60 个上班提醒，再次打开 App 补排；不能保证系统准时投递。

备份恢复

设置中导出完整 JSON 备份。恢复会替换当前班表，并保留原文件安全副本。卸载或换机前请备份，损坏数据不要反复清空。

联系

请说明 App 版本、iOS 版本和复现步骤，可附不含私人班表的截图。
