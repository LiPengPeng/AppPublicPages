プライバシーポリシー

本ポリシーは、ShiftFlowがアプリ内データと本ウェブサイトのアクセス情報をどのように扱うかを説明します。

更新日と対象

更新日：2026年10月17日。本ポリシーはShiftFlow iOSアプリと本ウェブサイトに適用されます。

端末内の記録

シフト、繰り返し設定、日付の変更、メモ、設定、復元前の安全コピーは端末内のアプリ領域に保存されます。開発者がこれらの勤務表データを受け取ったりアップロードしたりすることはありません。フィードバックは、あなたが送信を選んだ場合にのみ送られます。詳しくは下記の「フィードバックのプライバシー」をご覧ください。iOS の端末バックアップに含まれるかはシステム設定によります。広告 SDK やトラッキング SDK は使用していません。

通知

通知の許可は、あなたが勤務リマインダーを有効にしたときだけ求めます。リマインダーは端末内で登録され、通知には入力したシフト名と時刻が含まれますが、開発者のサーバーには送信されません。

共有・バックアップ・メール

書き出しや共有は、あなたが選んだときだけ行われます。バックアップには勤務表とメモが含まれ、月間画像にはメモが含まれません。受信者や選択したサービスは独自の規則でファイルを扱います。サポートへの連絡では、あなたが送信した内容がサポート担当者に届きます。パスワードや不要な個人情報は送らないでください。

削除

勤務表を消去するとシフトのテンプレートは残り、繰り返し設定、日付の変更、リマインダーが削除されます。書き出したバックアップや安全コピーは削除されません。アプリを削除すると端末内のアプリ領域が消えます。システムバックアップと外部ファイルは別途管理してください。

外部サービス

公開ページはGitHub Pagesでのホスティングを予定しており、閲覧時にIPアドレスなどの一般的なリクエスト情報が処理される場合があります。App Storeでの購入はAppleが処理します。プライバシーに関するご質問はサポートページへ。

フィードバックのプライバシー

フィードバックはご自身の操作で送信され、アプリの改善と問題の解決のために Cloudflare を通じて受信・保存されます。入力内容、任意の利用場面と連絡先、選択したアプリ・iOS のバージョンと表示言語が開発者に送信されます。シフト表、メモ、デバイス識別子は添付されません。サービス提供者は通信と不正利用防止のために IP アドレスなどの情報を処理しますが、IP はフィードバックの記録に保存しません。フィードバックの記録は180日後に定期削除されます。提供者のバックアップはその保持規則に従います。削除を希望する場合は受付番号を添えてサポートにご連絡ください。
