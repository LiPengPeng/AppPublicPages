本机记录

班次、循环、日期调整、备注、偏好和恢复安全副本保存在 App 本机沙盒。开发者不接收或上传这些数据；没有账号、广告、分析或追踪 SDK。系统设备备份可能包含这些文件，由系统设置决定。

通知

仅在你主动开启上班提醒时请求系统通知权限。提醒在本机安排，通知内容包含你填写的班次和时间，不发往开发者服务器。

分享、备份和邮件

仅在你主动选择时导出或分享。备份包含班表和备注，月历图片不包含备注。收件方与所选服务按照各自规则处理文件。联系支持会向支持方提供你主动发送的内容；请勿发送密码或不必要的私人资料。

删除

清空班表保留班次模板，移除循环、日期调整与提醒；不会删除导出的备份或恢复安全副本。卸载移除本机应用容器；系统备份与外部文件需在各自位置管理。

外部服务

公开网页计划由 GitHub Pages 托管，访问时托管方可能处理 IP 地址等常规网络请求信息。App Store 购买由 Apple 处理。隐私问题请访问本站支持页。
