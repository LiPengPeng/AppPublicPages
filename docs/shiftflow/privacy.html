隐私政策

本政策说明班序如何处理应用数据和本网站的访问信息。

更新日期与范围

更新日期：2026-10-17。本政策适用于班序 iOS App 及本网站。

本机记录

班次、循环、日期调整、备注、偏好和恢复安全副本保存在 App 本机沙盒。开发者不接收或上传这些班表数据；反馈仅在你主动提交时发送，处理方式见下方「反馈隐私说明」。系统设备备份可能包含这些文件，由系统设置决定。App 不使用广告或追踪 SDK。

通知

仅在你主动开启上班提醒时请求系统通知权限。提醒在本机安排，通知内容包含你填写的班次和时间，不发往开发者服务器。

分享、备份和邮件

仅在你主动选择时导出或分享。备份包含班表和备注，月历图片不包含备注。收件方与所选服务按照各自规则处理文件。联系支持会向支持方提供你主动发送的内容；请勿发送密码或不必要的私人资料。

删除

清空班表保留班次模板，移除循环、日期调整与提醒；不会删除导出的备份或恢复安全副本。卸载移除本机应用容器；系统备份与外部文件需在各自位置管理。

外部服务

公开网页计划由 GitHub Pages 托管，访问时托管方可能处理 IP 地址等常规网络请求信息。App Store 购买由 Apple 处理。隐私问题请访问本站支持页。

反馈隐私说明

反馈由你主动提交，通过 Cloudflare 接收和保存，用于改进 App 和处理问题。你填写的建议、使用场景和联系方式，以及自愿附带的 App/iOS 版本和界面语言，会发送给开发者。我们不附带班表、备注或设备标识。服务商会处理 IP 地址等网络请求信息以传输和防止滥用；IP 不写入反馈记录。反馈记录在 180 天后定期清理，服务商备份按其规则保留。需要删除时，请提供回执编号联系支持。
